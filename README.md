# SSTP VPN для Arch Linux

## Установка

Распакуйте папку на новом компьютере, откройте терминал в ней и выполните:

```bash
chmod +x install.sh
./install.sh
```

Установщик запросит пароль администратора и поставит NetworkManager, SSTP-плагин и графические зависимости. Затем приложение появится в меню и будет доступно командой:

```bash
sstp-vpn-gui
```

## Перенос настроек

Данные профилей и пароли шифруются в файле `connections.vault` рядом с приложением. Для переноса скопируйте этот файл вместе с папкой приложения. На новом ПК приложение запросит тот же мастер-пароль.

Фон и тема сохраняются в `~/.config/sstp-vpn/appearance.json`.
